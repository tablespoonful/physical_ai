- **Franka 公式**: 公式ドキュメントの配布ページと、公式リポジトリから取得しました。

## 制約

- 関連度の判定はキーワードによる機械的なものです。カタログには関連の薄い論文も混ざります。
- 引用数は使っていません。Semantic Scholar API がレート制限で使えなかったためです。
- 学会の採択情報は、公式一覧を取得できた学会だけ反映しています。ICRA、IROS、T-RO、RA-L は網羅できていません。CoRL 2026 は公式一覧からタイトルで抽出しました。NeurIPS 2026 は公式一覧を読めなかったため、arXiv に採択の記載がある 3 本だけです。
- `notes/themes.md` のテーマ分類は、タイトルと概要の冒頭に基づく機械的な分類です。本文は読んでいません。
- OpenReview の PDF はボット対策 (403) で取得できませんでした。公開版が見つからない ICLR 2026 論文は未保存です。
- 有料の学術誌の論文は対象外です。arXiv にない論文は `Franka` などの分野で漏れている可能性があります。
- 産業動向の数字は報道ベースです。各 README に出典を記載しています。
